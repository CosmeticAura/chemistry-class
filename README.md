## How each unit works

Every section goes read, short break, flashcards, break, brain dump, then you mark how well it stuck. The memory jog is a quick pass over every topic with the formulas and mnemonics to memorize. Progress saves in your browser, so you can close the tab and pick up where you left off.

## Layout

```
index.html        home page with every unit
unit-1/           matter and measurement
unit-2/           atomic structure
review/           all units combined
mock-test/        practice test you grade yourself
img/              diagrams and lab tool pictures
```

- `diagnostic/` is a 26 question check with an answer key. `fast-review/` is unit 2 in 3 quick loops.
